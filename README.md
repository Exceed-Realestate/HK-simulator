# HK Investor Strategy — EXIT Simulator

Interactive strategy paper and exit simulator for Hong Kong-based investors considering Dubai property, prepared by **EXCEED REAL ESTATE L.L.C.**

## Contents

- **`Exceed_EXIT_Simulator.html`** — Single-file interactive deliverable. Open in any modern browser. Includes:
  - Bilingual toggle (日本語 / English)
  - Q1–Q3 strategy paper (financing, capital outlay, exit)
  - Interactive exit simulator with 8 property presets
  - Brochure modal with download links
  - Print / PDF export
- **`exceed_logo.jpg`** — Company logo
- **`brochures/`** — Property PDF brochures (see folder README for naming)
